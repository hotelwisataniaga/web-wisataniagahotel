WISATA NIAGA HOTEL - MODERN WEBSITE
===================================

Cara tes lokal paling gampang:
1. Extract ZIP ini.
2. Buka folder hasil extract.
3. Double-click index.html.

Disarankan untuk pengujian paling akurat memakai local web server:
- Windows + Python: buka Command Prompt di folder ini lalu jalankan:
  python -m http.server 8000
- Setelah itu buka http://localhost:8000

Struktur deploy Hostinger:
Upload ISI folder ini langsung ke public_html, bukan folder induknya.

Halaman:
- index.html : Beranda, kamar, fasilitas, lokasi, booking WhatsApp
- mice.html  : MICE / meeting / event
- cafe.html  : WN Cafe
- 404.html   : Halaman error

Folder:
- css/       : style.css global
- js/        : script.js global
- images/    : aset gambar
- pdf/       : menu WN Cafe

Catatan:
- Form booking membuka WhatsApp; belum merupakan booking engine/backend.
- Google Maps membutuhkan koneksi internet.
- Foto kamar sumber beresolusi kecil, sehingga kualitas visualnya terbatas bila diperbesar.
